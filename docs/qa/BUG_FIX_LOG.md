## Investigation notes

The long-card pointer test initially aimed at a handle whose position continued changing during edge auto-scroll. A candidate overlay/collision change was tested, then removed: with a visible, settled destination, the original implementation correctly moved the first project to the exact third position. The final regression asserts stored source IDs in order, separately exercises keyboard bullet sorting and keeps arrow alternatives. This was a test-harness defect and is not counted as an application bug.

Selector ambiguities in new tests (Delete versus Delete bullet, Import behavior versus acknowledgement, duplicate Create profile entry points) were corrected by scoping. No assertion was removed to conceal an application failure.

The existing optional PDF bundle size warning is retained and documented. Extreme user-selected typography can create sparse final pages; the renderer preserves all content rather than silently reducing font sizes or omitting evidence.
